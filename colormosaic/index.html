BASIC RULE PUZZLE

ColorMosaic

数字と色の関係を、候補メモを置きながら確かめる。

使う色

操作

タップ：着色 → × → なし
長押し：すぐ×

操作とルール

数字は、周囲8マスにある「数字マス自身と同じ色」の数です。数字マス自身は数えません。

Extra問題では、問題名に表示された追加ルールも同時に満たします。「各行・各列に全色」は、問題で使う3色または4色を各行・各列に最低1マスずつ使います。同じ色が行・列に複数あっても構いません。

  • 色を選んでタップすると、選択色の「着色 → × → なし」を繰り返します。
  • マスを長押しすると、選択色の×を直接付けます。
  • 着色済みの数字マスを長押しすると、周囲の未着色マスに数字マスと同じ色の×をまとめて付けます。
  • 盤面の外側をダブルタップまたは長押しすると、n−1色の×があるマスを残り一色で確定します。
  • 仮置きモードでは「着色 → × → なし」を繰り返し、色と×は確定情報と区別して表示します。
  • 「全確定」で仮置きの色と×をまとめて確定し、「全消去」で仮置きだけを消せます。
  • 色別の×は色ごとの位置に分けて表示します。
  • 盤面内の色アルファベットは表示設定で切り替えられ、初期状態では非表示です。
  • T で仮置きモードを切り替えます。
  • Ctrl＋Z でUndo、Ctrl＋Shift＋Z でRedoできます。
